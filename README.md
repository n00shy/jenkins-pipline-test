# 🔧 Jenkins CI/CD Pipeline with Docker Compose

A hands-on Jenkins project demonstrating how to build and automate a containerized application delivery pipeline.

## 🎯 What this project demonstrates

- Jenkins Pipeline as Code
- Docker Compose based application stack
- Automated source checkout
- Docker image build workflow
- CI/CD stage organization
- Credentials and environment variables
- Containerized development and delivery

## 🔄 Pipeline concept

```text
GitHub
  ↓
Jenkins
  ↓
Checkout
  ↓
Build / Test
  ↓
Docker Build
  ↓
Docker Image
  ↓
Deployment
```

## 🧰 Technologies

- Jenkins
- Jenkinsfile
- Docker
- Docker Compose
- GitHub
- Linux

## 🚀 Run the application

```bash
docker compose up -d --build
```

## 💡 DevOps focus

The main goal is to demonstrate **repeatable CI/CD automation** instead of manually building and deploying containers.
